# 우리반운영센터

교사와 학생이 한 번 로그인해 학급 운영, 수업 달력, 직업, 금융, 마트, 생활확인을 함께 사용하는 Cloudflare 기반 통합학급운영시스템입니다. 교사는 준비와 문제 해결을 돕고, 학생은 맡은 직업에 따라 실제 운영에 참여합니다.

## 구현 범위

- 교사 이메일 가입·로그인·비밀번호 재설정
- 한 교사 계정에서 여러 학급 관리
- 학급별 학생 번호·공식 이름 일괄 등록
- 동명이인 허용, 학급 내 번호 중복 차단, 변하지 않는 학생 내부 ID
- 학생별 재사용 QR, 최초 활성화·비밀번호 재설정, QR 카드만 담은 A4 인쇄
- 학교·학년·반·번호·비밀번호 학생 로그인
- 학생 잠금·해제·명단 제외(기록 보존)
- 학생 수에 맞춘 우리 반 직업 추천·직접 만들기·초안·확정
- 대한민국 표준시 월간 수업 달력과 교시별 기초 시간표
- 직업 운영일 달력, 첫 직업 배정, 학생 직업평가와 다음 달 무작위 선택 순서
- 이중 원장 기반 학급 금융, 입출금, 직업 월급, 예금, 주식, 펀딩, 통계와 감사 기록
- 디지털 금융과 분리된 현물화폐 마트의 상품·재고·판매 기록
- 양치·우유·급식 생활확인과 기간별 보상 명단
- 교사와 학생의 서버 세션 및 소유권 기반 권한 분리
- 로그인·비밀번호 재설정 요청 횟수 제한과 감사 로그

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

로컬 주소는 `http://localhost:3000`입니다. D1 호환 로컬 저장소는 `.wrangler/` 아래에 생성되며 Git에 포함되지 않습니다.

## 검사

```bash
npm test
```

빌드와 서버 렌더링 기본 검사를 실행합니다. 개발 서버가 켜진 상태에서는 다음 명령으로 교사 가입부터 학생 QR 활성화·권한 분리·비밀번호 복구까지 실제 API 흐름을 확인할 수 있습니다.

```bash
npm run test:integration
```

스키마 변경 후 마이그레이션을 다시 만들려면 `npm run db:generate`를 실행합니다.

## 배포 환경

- Cloudflare Worker 이름: `job-classroom`
- D1 바인딩 이름: `DB`
- 교사 비밀번호 재설정 메일(선택이 아니라 운영 전 필수):
  - `RESEND_API_KEY`
  - `MAIL_FROM` (예: `우리반운영센터 <account@example.com>`)

직접 배포 준비와 전환 순서는 [`docs/CLOUDFLARE_MIGRATION.md`](docs/CLOUDFLARE_MIGRATION.md)에 정리되어 있습니다. 실제 운영본은 Git 저장소에서 빌드해 Cloudflare Worker와 D1에 직접 배포합니다.

학기계획 엑셀, 수업자료 링크와 GPT 검색을 차례로 연결하기 위한 기준은 [`docs/teaching-calendar-roadmap.md`](docs/teaching-calendar-roadmap.md)에 정리했습니다.

비밀번호 원문과 QR 토큰 원문은 저장하지 않습니다. 비밀번호는 PBKDF2-SHA-256으로, 세션·QR·재설정 토큰은 SHA-256 해시로 저장됩니다.

## 교사 가입 기반

초대 방식으로 운영할 때 신규 교사는 다음 순서로 가입합니다.

1. 일반 이메일과 비밀번호로 계정 생성
2. 15분 동안 한 번만 사용할 수 있는 이메일 링크 확인
3. 일회용 교사 초대코드 인증
4. 나이스 공식 학교 검색·선택 또는 학교 직접 입력
5. 학급 생성

친한 교사에게 바로 가입을 열 때는 `OPEN_TEACHER_REGISTRATION`을 켭니다. 이 경우 첫 정상 로그인에서 이메일·초대코드 단계를 안전하게 완료 처리하고 학교 선택부터 안내하며, 계정별 학급·학교 요청 상한은 그대로 적용됩니다.

기존 교사 계정은 배포 시 이메일 확인·초대코드 인증 완료 상태로 안전하게 이관합니다. 기존 학급의 학교명은 별도의 `학교 확인 중` 요청으로 보존되며 공식 학교 데이터와 섞이지 않습니다.

추가 운영 환경값:

- `SYSTEM_ADMIN_USERNAME`, `SYSTEM_ADMIN_PASSWORD_HASH`, `SYSTEM_ADMIN_PATH`: 운영자 로그인과 숨겨진 관리자 경로용 Worker Secrets
- `NEIS_API_KEY`: 전국 학교 기준 데이터 동기화용 나이스 인증키

초대코드 원문은 생성 응답에서 한 번만 확인할 수 있고 DB에는 해시만 저장됩니다. 관리자 화면은 일반 경로에서 숨기고 별도 관리자 세션과 CSRF 검증으로 보호합니다.

## 전국 학교 데이터 갱신

나이스 `학교기본정보`를 재실행 가능한 SQL로 준비합니다. 인증키는 명령 인자나 저장소에 넣지 않고 `NEIS_API_KEY` 환경 변수로만 전달합니다.

```bash
npm run schools:prepare
npx wrangler d1 execute DB --remote --file=.data/schools.sql
```

생성 SQL은 학교 행정표준코드를 기준으로 upsert하고, 재실행해도 중복을 만들지 않습니다. 최신 원본에서 사라진 학교는 삭제하지 않고 `inactive` 상태로 바꿔 기존 사용자 연결을 보존합니다. `.data/`는 Git에 포함되지 않습니다.

## 마이그레이션

`drizzle/`의 순차 마이그레이션은 학교·직업·금융·마트·생활확인 데이터를 기존 학급과 연결하고, 원장 불변성·중복 방지·상태 전환을 D1 트리거로 함께 보호합니다. 새 버전은 기존 운영 데이터와 마이그레이션 이력을 보존한 채 아직 적용되지 않은 파일만 순서대로 실행합니다.
