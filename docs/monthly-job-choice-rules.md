# 다음 달 직업 선정 규칙

## 과거 직업센터에서 옮긴 것

- 지난달 배정과 직업 등급을 월 마감 시점의 변경 불가능한 기록으로 남긴다.
- 다음 달 선택 순서는 `C → B → A` 등급 순으로 만든다.
- 같은 등급 안에서는 기본적으로 학생 번호순을 사용하고, 교사가 원하면 등급 묶음 안에서만 순서를 섞는다.
- 학생이 한 명씩 직업을 고르면 해당 직업의 남은 자리를 바로 줄이고, 정원이 찬 직업과 이미 선택한 학생은 다시 선택할 수 없게 한다.
- 현재 학생, 다음 학생, 남은 자리, 선택을 마친 학생을 같은 화면에 보여 주고 마지막 선택은 한 번 되돌릴 수 있게 한다.
- 모든 학생의 선택을 마친 뒤 교사가 한 번 확정하면 다음 달 배정 기록을 만든다.

## 현재 제품에 맞게 개선한 것

- 지난달 결과, 학생 명단, 직업, 정원, 달력 월은 서버의 현재 저장값에서 자동으로 불러온다.
- 과거 이름 기반 연결 대신 학생과 직업의 안정적인 ID를 사용한다.
- 같은 등급의 기본 순서는 이름순이 아닌 학생 번호순으로 고정한다.
- 등급 안에서 섞은 순서는 서버에 저장해 새로고침하거나 다시 로그인해도 바뀌지 않게 한다.
- 지난달에 없던 전입생은 `새 학생` 묶음으로 구분해 기존 등급 순서 뒤에 배치한다.
- 교실에서 한 명씩 고르는 동안에는 브라우저에 즉시 저장하고, 교사가 최종 확정할 때만 서버에 원자적으로 한 번 전송한다.
- 최종 확정 때 학생 중복, 직업 정원, 명단 변경, 직업 설정 변경, 오래된 화면을 서버에서 다시 검증한다.

## 이번 기능에서 제외한 것

- 과거 단일 HTML/전역 상태/Firestore 문서 덮어쓰기 구조
- `Math.random()`에 의존하는 복원 불가능한 순서 섞기
- 급여, 벌점, 경고, 해고 평가와 D등급 운영
- 클라이언트만 믿는 정원·중복 검증

현재 제품에는 급여·평가 결과가 아직 없으므로, 월 마감 때 교사가 지난달 직업별 등급만 검토해 확정한다. 학생·직업·정원은 다시 입력하지 않는다.
