# 다음 달 직업 선정 규칙

## 과거 직업센터에서 이어받은 운영 원칙

- 지난달 배정 결과와 평가를 마감 기록으로 남긴 뒤 다음 달 선정의 기준으로 사용한다.
- 선택 우선순위는 `C → B → A → 신규 → D` 순서다.
- 학생이 한 명씩 직업을 고르면 해당 직업의 남은 자리를 즉시 줄이고, 정원이 찬 직업과 이미 선택한 학생은 다시 선택하지 못하게 한다.
- 현재 학생, 다음 학생, 남은 자리, 선택을 마친 학생을 교실 화면에서 함께 보여 준다.
- 모든 학생이 선택을 마친 뒤 교사가 한 번 확정하면 다음 달 배정 기록을 만든다.

## 현재 제품에 맞게 구현한 평가 규칙

- 지난달 실제 배정 직업과 학생 명단을 서버에서 자동으로 불러온다. 교사가 다시 입력하지 않는다.
- 학생은 자신이 배정받았던 직업만이 아니라 지난달에 운영된 모든 직업을 평가한다.
- 각 직업을 `힘듦`, `책임감`, `꾸준함`, `부담감` 네 항목으로 평가하며 각 항목은 1점부터 5점까지다.
- 직업별로 네 항목의 평균을 계산하고, 네 평균의 합계를 직업 점수로 사용한다.
- 점수가 높은 순서로 상위 3개 직업은 A, 4위부터 8위는 B, 나머지는 C를 추천한다.
- 경계 순위에서 동점이 생겨도 직업 수 기준으로 A 3개, B 5개를 유지하며 교사 화면에 동점 안내를 표시한다.
- 교사는 학생 평가가 끝난 뒤 추천 등급을 확인하고 필요하면 직업별 최종 등급을 수정한 다음 확정한다.
- 학생 자기평가는 별도 기능으로 다루며 직업 등급이나 다음 달 선택 순서 계산에는 넣지 않는다.

## 같은 등급 학생의 순서

- 같은 등급 안에서는 학생 번호나 이름순을 사용하지 않는다.
- 다음 달 선택 회차를 만들 때 서버에서 등급별 순서를 자동으로 무작위 배정하고 그 결과를 저장한다.
- 따라서 새로고침하거나 다시 로그인해도 순서는 바뀌지 않는다.
- 아직 아무도 직업을 고르지 않았다면 교사가 같은 등급 안의 순서를 다시 섞을 수 있다.
- 재배열은 등급 간 우선순위 `C → B → A → 신규 → D`를 바꾸지 않는다.

## 빠르고 안전한 선택 흐름

- 학생이 직업을 고르는 동안의 진행 상태는 교실 브라우저에 즉시 저장한다.
- 교사가 최종 확정할 때만 전체 선택 결과를 서버로 한 번 전송한다.
- 최종 확정 시 서버는 학생 중복, 직업 정원, 명단 변경, 직업 설정 변경, 오래된 화면 여부를 다시 검증한다.
- 지난달 결과, 학생 명단, 직업 목록, 정원, 달력 정보는 현재 저장 데이터를 연결해 사용한다.

## 이번 기능에서 제외한 과거 구조

- 과거 단일 HTML, 전역 상태, Firestore 문서에 얽힌 기술 구조
- `Math.random()` 결과에만 의존하고 순서를 저장하지 않는 방식
- 벌점, 경고, 해고 평가와 D등급 자동 운영
- 학생 이름으로 기록을 연결하는 방식
- 브라우저에서만 믿는 정원·중복 검증
