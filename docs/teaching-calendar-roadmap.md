# 수업 달력 확장 기준

## 지금 구현하는 범위

- 교사 화면에서 대한민국 표준시 기준의 월간 달력을 확인한다.
- 학급별 기초 시간표를 월요일부터 금요일까지, 교시별 과목으로 저장한다.
- 달력에서 날짜를 고르면 그 요일의 수업을 바로 보여 준다.
- 기존 직업 운영일 달력은 읽기만 한다. 시간표를 고쳐도 직업 배정이나 생활확인 계산에는 영향을 주지 않는다.

## 학기계획 엑셀 가져오기

후속 개발에서는 시간표를 다시 입력시키지 않고 학기계획 파일의 날짜·교시·과목을 현재 시간표와 연결한다.

1. 파일을 올리면 곧바로 저장하지 않고 먼저 미리보기를 만든다.
2. 열 이름이 달라도 `날짜`, `교시`, `과목`, `수업 내용`, `자료 링크`로 연결할 수 있게 한다.
3. 잘못 연결된 행과 중복 행을 따로 보여 주고, 교사가 확인한 내용만 저장한다.
4. 같은 파일을 다시 올려도 같은 수업이 두 번 생기지 않도록 가져오기 기록을 남긴다.
5. 원본 파일과 반영 결과를 함께 기록해 언제든 원인을 확인할 수 있게 한다.

학기계획은 기초 시간표와 다른 저장소를 사용한다. 권장 구조는 날짜와 교시를 기준으로 하는 `class_lesson_plans`와, 가져오기 단위를 기록하는 `class_lesson_plan_imports`다.

## 수업자료 링크와 GPT 검색

수업자료 링크는 메모 안에 섞지 않고 수업계획에 연결된 별도 자료 목록으로 저장한다. 한 수업에 여러 링크를 붙이고 순서를 바꿀 수 있어야 한다.

GPT 기반 자료 찾기는 다음 원칙으로 추가한다.

- 교사가 `자료 찾기`를 눌렀을 때만 검색한다.
- 과목과 수업 주제만 전송하고 학생 이름·평가·금융 정보는 전송하지 않는다.
- API 키는 Cloudflare Secret에만 보관하고 브라우저로 보내지 않는다.
- 결과에는 제목, 원문 주소, 출처와 간단한 설명을 함께 보여 준다.
- 검색 결과를 자동 저장하지 않고 교사가 고른 링크만 수업에 연결한다.
- 같은 주제의 반복 검색은 잠시 보관해 비용과 대기 시간을 줄인다.
- 교사가 저장한 링크를 열 때도 `https` 주소인지 다시 확인한다.

## 확장 순서

1. 기초 시간표와 월간 수업 보기
2. 학기계획 엑셀 미리보기·확정 가져오기
3. 날짜별 수업 내용과 자료 링크
4. GPT 자료 검색과 선택 저장
5. 필요할 때만 반복 일정, 알림, 학교 일정 연동

이 순서를 지키면 지금 쓰는 시간표를 버리지 않고 다음 기능을 차례로 붙일 수 있다.
